# Правила работы с репозиторием

Эти правила действуют для всего проекта.

## Коммиты и пуш

- После каждого изменения создавай отдельный коммит с понятным описанием.
- В конце задачи выполняй пуш всех созданных в рамках задачи коммитов в удалённый репозиторий.

## Релизы

- Создавай релиз только по явной просьбе пользователя.
- Только такая просьба разрешает создавать и отправлять теги релизов, запускать workflow `Release` и публиковать GitHub Release.
- Обычный запрос на изменение, коммит или пуш не разрешает выпуск релиза.
