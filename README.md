# Карточки ККТ — Rust / Windows

[![CI](https://github.com/Lairon1/kkt-saver/actions/workflows/ci.yml/badge.svg)](https://github.com/Lairon1/kkt-saver/actions/workflows/ci.yml)

Практичное приложение для чтения, поиска места хранения, сохранения и печати PDF-карточек регистрации и снятия ККТ с учёта.

Версия **2.5.3**: при сворачивании в трей приложение приостанавливает перерисовку окна, чтобы снизить расход процессора. РНМ отображается и копируется группами по четыре цифры через пробел — например, `0008 5411 0801 4111`. Выбранная папка выделяется прямо в списке без дублирующих строк под ним. Сохранение по структуре **организация → РНМ → карточки**, даты создания и изменения файла из карточки и отдельный сортировщик существующего архива. **Карточки за все годы сохраняются; возраст не ограничивается. Одинаковые копии при сортировке сохраняются отдельно.**

## Запуск

Запустите `dist\kkt-saver.exe`. Установка, Java и внешний PDF-просмотрщик не требуются. Сборка предназначена для Windows 10/11 x64. PDFium встроен в EXE и при первом чтении PDF извлекается в `%LOCALAPPDATA%\KktSaver\runtime`. Интернет при работе не нужен.

Папка архива по умолчанию:

```text
Z:\!Общие документы\!!!ЦТО\!КАРТОЧКИ РЕГИСТРАЦИИ
```

Её можно изменить в «Настройках». Можно указать UNC-путь к сетевой папке. Приложение следует запускать от обычного пользователя: сетевой диск Z: должен быть подключён в той же учётной записи.

## Как пользоваться

1. Перетащите PDF в окно или нажмите «Открыть PDF…».
2. Проверьте распознанные данные на вкладке «Данные карточки». **Кнопка с иконкой двух листов** напротив поля копирует только его значение — например, РНМ, ИНН или заводской номер, без подписи поля и с сохранением ведущих нулей. **РНМ отображается и копируется с пробелами через каждые четыре цифры**, в том числе при копировании всех реквизитов. В окне сохранения РНМ также показан с пробелами; вручную можно ввести номер с пробелами или без них. В именах папок и PDF используется РНМ из 16 цифр без пробелов. При наведении показывается подсказка с названием поля, а после нажатия рядом всплывает сообщение **«Скопировано»** на 1,5 секунды. Для пустых полей копирование недоступно. Справа расположен предпросмотр с переключением страниц. Вкладка «Текст PDF» показывает весь извлечённый текст с номерами строк.
3. При необходимости включите два независимых переключателя:
   - **Печатать карточку** — после сохранения отправить все страницы на текущий принтер Windows по умолчанию.
   - **Удалить исходник (перенести)** — после записи и проверки копии удалить исходный файл. При выключенном переключателе исходник остаётся на месте.
4. Нажмите **«Сохранить карточку»**. Откроется компактный список до 10 корневых папок организаций: одна организация — одна строка. Отображается название её папки непосредственно внутри настроенного архива. Вложенные папки с датами и цифровые папки без названия организации отдельными результатами не выводятся. Наведите курсор на строку, чтобы увидеть полный путь и отличить папки с одинаковыми названиями.
5. Выберите результат. Поиск обновляется при вводе: можно изменить поисковую строку, уточнить ИНН либо нажать **«Выбрать вручную…»**. Ручной выбор доступен и вне корневой папки архива.
6. Выбранная папка **выделена в списке**; папка, выбранная вручную или созданная через приложение, также появляется в списке и выделяется. Проверьте РНМ, дату карточки и имя PDF, затем нажмите **«Сохранить»**. Программа создаёт или использует папку РНМ внутри выбранной организации. Для быстрого сохранения можно **дважды щёлкнуть по папке в списке** — применяются те же правила и настройки печати/переноса. Не распознанные РНМ или дату нужно ввести по предпросмотру. Полный путь доступен при наведении на папку.

Файл записывается по кнопке «Сохранить», двойному щелчку по папке или сочетанию Ctrl+Enter. Открытие, поиск и индексация не изменяют содержимое архива.

### Структура и даты

```text
Корень архива\
  ООО Рога и копыта\
    0001234567890123\
      2018-07-27 Регистрация РН 0001234567890123 ЗН 12345.pdf
      2025-02-06 Снятие РН 0001234567890123 ЗН 12345.pdf
  ИП Иванов Иван Иванович\
    0009876543210987\
      ...
```

Юридические формы сокращаются: ООО, ИП, ОАО, ЗАО, ПАО, АО, МУП, ГУП, ФГУП, ПО. Ведущие нули РНМ сохраняются. Если выбрана старая папка с номером вроде `045_ООО Гонг`, новый файл попадёт в чистую соседнюю папку `ООО Гонг\РНМ`. Старую папку приложение не переименовывает. Ручной выбор вложенной папки в настроенном архиве также приводит к организации и папке РНМ.

- Используется видимая дата формирования/выдачи карточки или отдельная дата в нижней части документа после подписи. Если её нет, для снятия используется дата снятия; для регистрации — видимая дата последнего отчёта/изменения.
- Дата первоначальной регистрации ККТ, срок действия сертификата и метаданные PDF не подменяют дату формирования.
- Создание и изменение файла устанавливаются на выбранную дату, **00:00 МСК (UTC+03:00)**. PDF не пересоздаётся и его содержимое не меняется.
- Если дата не распознана, в окне сохранения её можно ввести вручную. Возраст карточки не препятствует сохранению.
- При ошибке установки дат исходник остаётся на месте; автоматический переход к следующей карточке останавливается.

### Очередь карточек

- Перетащите несколько PDF: первый откроется, остальные появятся на левой панели «Документы» отдельными пронумерованными блоками. Полный путь виден при наведении на имя.
- Нажмите имя, чтобы открыть нужную карточку. Текущая несохранённая карточка при таком переключении возвращается в начало очереди.
- Крестик **×** в блоке убирает карточку из очереди. Удаление записи из очереди доступно и во время сохранения другой карточки.
- Переключатель **«Следующая после сохранения»** находится над очередью; он также доступен в «Настройках → Очередь карточек». По умолчанию выключен, выбранное значение сохраняется между запусками.
- При включённом автопереходе после успешного сохранения и завершения печати открывается первая оставшаяся карточка. Сохранять следующую карточку пользователь подтверждает сам. При ошибке сохранения, печати или предупреждении о переносе текущая карточка остаётся открытой. После успешной повторной печати автопереход продолжается.
- Если очередь закончилась или автопереход выключен, сохранённая карточка остаётся открытой.

### Если подходящей папки нет

1. В окне «Папка сохранения» нажмите **«Создать папку…»** рядом с ручным выбором. Кнопка доступна и при пустом списке результатов.
2. Проверьте родительскую папку: по умолчанию это корень архива. Путь можно изменить вручную или через **«Обзор…»**.
3. Проверьте название новой папки. Оно подставляется из названия организации в карточке: полная форма ООО сокращается, для ИП добавляется соответствующий префикс, недопустимые для Windows символы убираются. Название можно отредактировать.
4. Нажмите **«Создать и выбрать»**. Новая папка создаётся и автоматически выбирается для сохранения; её путь добавляется в локальный индекс без обхода архива.
5. Нажмите **«Сохранить»** в окне выбора папки, чтобы записать саму карточку.

Создание выполняется в фоне. Существующие папки и файлы не заменяются. Если название занято, путь недоступен или нет прав, сообщение появляется в диалоге, где можно исправить данные. «Отмена» закрывает диалог без создания папки.

### Интерфейс и клавиатура

Тёмные панели, синие акценты, вкладки редактора и боковые рабочие панели оформлены в стиле IntelliJ IDEA. Текст PDF и технические строки используют встроенный JetBrains Mono. Панели документов и предпросмотра можно скрыть кнопками слева или через меню «Вид», ширину панелей можно менять перетаскиванием границ.

| Клавиши | Действие |
| --- | --- |
| Ctrl+O | Открыть PDF |
| Ctrl+S | Начать сохранение и выбрать папку |
| Ctrl+F | Открыть поиск папки |
| ↑ / ↓ в окне выбора папки | Выбрать результат |
| Ctrl+Enter в окне выбора папки | Сохранить в выбранную папку |

Карточка снятия открывается с заголовком **«Снятие ККТ с учёта»**, отдельной цветовой меткой и датой снятия. Для неё показываются данные владельца, модель, заводской и регистрационный номера ККТ и сведения о снятии. Поля ФН, адреса и ОФД отображаются, если они присутствуют в документе. При отсутствии даты программа явно просит проверить PDF.

Предлагаемое имя карточки снятия: `2025-02-06 Снятие РН 0008541108014111 ЗН 0614850012279840.pdf`. Поиск папки, копирование, перенос и печать работают для обоих типов карточек одинаково.

Закрытие окна крестиком скрывает его в трей. Щелчок по значку возвращает окно. Для полного завершения выберите **«Выйти из программы»** в контекстном меню значка. Во время записи или печати полный выход откладывается: дождитесь окончания и выберите выход повторно. Если создать значок трея не удалось, приложение сообщает об этом и закрывается обычным способом.

В версии 2.2.1 обработчики трея восстанавливают нативное окно непосредственно через Windows, затем передают команду интерфейсу. Поэтому восстановление и штатный выход работают после скрытия окна, когда отрисовка интерфейса приостановлена. Системная шапка использует тёмный режим; в Windows 11 её фон соответствует цвету панелей приложения.

## Какие данные распознаются

Тип карточки, организация или ФИО ИП, ИНН, КПП, ОГРН/ОГРНИП, модель и заводской номер ККТ, регистрационный номер, модель и номер ФН, адрес и место установки, даты регистрации/изменения/снятия, число перерегистраций, ОФД и его ИНН, признаки применения, текстовые сведения об электронной подписи.

Поддерживаются старые и новые текстовые PDF, многострочные поля и таблицы, в которых значения физически записаны отдельно от подписей. Для карточек снятия учитываются варианты «снятие с учёта» / «снятие с регистрационного учета», переносы заголовка, краткие подписи номеров ККТ, даты с разделителями `.`, `/`, `-` и даты ISO. Порядок строк восстанавливается по координатам символов. Не найденные основные поля отмечаются явно. Исходный PDF сохраняется без пересоздания и изменения байтов; электронная подпись файла не переписывается. Криптографическая проверка подписи не выполняется.

**Сканы:** OCR не включён. PDF без текстового слоя можно просмотреть и сохранить, выбрав организацию и введя РНМ и дату по предпросмотру. DOC/DOCX, изображения и защищённые паролем PDF не открываются в приложении; сортировщик сохраняет возможные карточки для ручной проверки.

## Поиск папок

- Фоновый обход всех вложенных папок, до четырёх одновременных запросов к файловой системе. Символические ссылки не обходятся.
- Полная индексация выполняется каждые 60 минут после завершения предыдущего обхода, в том числе в трее. При старте свежий кэш используется до истечения этого интервала; если кэша нет, он устарел или изменён корень архива, выполняется полный обход.
- Сохранение карточки, создание папки, открытие выбора папки и возврат из трея не запускают полный обход. В индекс точечно добавляются путь созданной папки и имя сохранённого PDF; новые ИНН и номера ККТ в имени сразу учитываются в поиске. Обновления сохраняются в локальный кэш и не сдвигают время очередной полной индексации. Пути вне настроенного архива не добавляются в его индекс.
- Ручной запуск доступен кнопкой **«Обновить индекс»** на главной панели, в окне выбора папки и настройках. Он запускает обновление сразу, не ожидая очередного часа. Во время текущего обхода кнопка показывает «Индексация…» и временно недоступна; ход работы виден в строке состояния.
- Если архив недоступен, программа повторяет попытку раз в минуту и сохраняет предыдущий индекс для поиска. Настройки и индекс хранятся локально; индексация не записывает ничего в архив.
- Первые результаты становятся доступны после чтения корневых папок; полный индекс дополняется в фоне.
- Локальный кэш названий и путей. При следующем запуске кэш доступен сразу, а при недоступном архиве остаётся пригодным для поиска. При сохранении доступность выбранной папки проверяется заново.
- Нормализация регистра, «ё/е», кавычек, пунктуации и полных юридических форм. Служебные номера и пометки «расторгнут», «безвозмездно» имеют пониженное значение.
- Инвертированный индекс слов и символьных триграмм сначала отбирает до 800 организаций, для каждой оцениваются её корневая папка и до четырёх лучших совпадений во вложенных папках. Затем выполняется уточняющее ранжирование с весами редких слов, Jaro–Winkler, совпадениями ИНН, регистрационного и заводского номеров, адреса и прошлых выборов пользователя.
- Учитываются имена уже лежащих в папке PDF; сами документы архива для индексации не открываются.
- В списке показана корневая папка организации с оценкой её лучшего совпадения. ИНН и номера ККТ из вложенных папок повышают её место в списке. Вложенные даты не занимают отдельные строки; при выборе сохраняется путь корневой папки организации. При сохранении внутри выбранной организации автоматически используется папка РНМ.
- Предупреждение о слабом совпадении показывается в подсказке при наведении. Оценки не выдаются за вероятности. Программа всегда ждёт выбора пользователя.
- Задержка поиска при вводе — 160 мс; расчёт выполняется в отдельном потоке, устаревшие результаты отбрасываются.

В проверке от 12 ноября 2026 года на заданном сетевом архиве: 7 472 папки, 0 ошибок обхода, полный обход 12,4 с, построение индекса 196 мс. В 125 запросах по пяти карточкам медиана поиска составила 7,0 мс, 95-й процентиль — 12,5 мс. Это измерения на текущем компьютере и подключении к сети.

## Сохранность файлов

- Существующие файлы не перезаписываются. При различном содержимом добавляется `(2)`, `(3)` и т. д.
- При повторном сохранении другого исходника с тем же именем и содержимым создаётся отдельная копия с числовым суффиксом. Если исходник уже находится по итоговому пути, обновляются его даты; единственный экземпляр не удаляется.
- Исходник сверяется с SHA-256, вычисленным при чтении карточки. Изменившийся файл требуется открыть заново.
- Запись идёт во временный файл в выбранной папке, затем проверяется и завершается без замены существующего файла.
- На время операции исходник блокируется от изменений и удаления. Сохранённая копия также проверяется и удерживается от изменения во время удаления исходника.
- При переносе удаляется именно открытый исходный файл по его Windows-дескриптору. Он удаляется только после успешной проверки копии. Недостаток прав удаления оставляет исходник на месте и выводит предупреждение.
- Сохранение в ту же папку под тем же именем не удаляет единственный экземпляр.
- Ошибка печати не отменяет успешное сохранение. Кнопка «Повторить печать» повторяет только печать.

Печать проверена через Microsoft Print to PDF: Windows принял задание, полученный PDF повторно прочитан и визуально проверен. Физическая печать не тестировалась. Очередь Windows подтверждает передачу задания, а не выход бумажного листа. Если принтером по умолчанию выбран виртуальный принтер, Windows может показать его диалог выбора выходного файла.

## Настройки и кэш

Папка `%LOCALAPPDATA%\KktSaver`:

- `settings.json` — корневая папка, состояния переключателей, последние выбранные папки организаций (до 300 записей).
- `folders-v2.json` — индекс папок и имён PDF. Содержимое карточек в этот индекс не записывается.
- `runtime\pdfium-8152-ba884cc5.dll` — встроенный движок PDF. Перед загрузкой проверяется соответствие встроенной копии.
- `last-error.txt` — последняя ошибка запуска, если возникла.

Переключатели по умолчанию выключены; изменения запоминаются. Тесты и диагностика могут задать отдельный профиль переменной окружения `KKT_SAVER_DATA_DIR`.

## Сортировка существующей папки

В комплекте находятся `kkt-organizer.exe` и `organize-cards.ps1`. Это отдельная консольная утилита с теми же правилами чтения карточек, дат и названий, что и приложение. Для неё не нужны Rust, Python или Java. Настройки приложения и корень Z: она не меняет.

### 1. Анализ без изменений

В PowerShell из папки комплекта:

```powershell
.\organize-cards.ps1 -Root 'C:\Users\Admin\Desktop\карточки регистрации' -ReportDir 'C:\Users\Admin\Desktop\kkt-sort-report'
```

В папке отчёта создаются `report.html` (список и поиск), `summary.txt` и `plan.json`. Отчёт должен находиться **вне** сортируемой папки. Для повторного анализа укажите новую папку отчёта.

- Карточки регистрации и снятия с распознанными организацией, РНМ и датой: организация → РНМ → PDF.
- Организации объединяются по ИНН; название берётся из самой новой карточки. Одинаковые названия с разными ИНН получают суффикс `ИНН …`.
- **Все годы и все одинаковые копии сохраняются.** При совпадении имён используются `(2)`, `(3)` и т. д.
- PDF проверяются по содержимому, в том числе полные PDF под расширением `.partial`.
- Сканы, изображения, повреждённые/непонятные PDF и карточки с недостающими реквизитами сохраняются в **«Неразобранные»**, с исходной структурой путей. OCR не используется. При непрочитанной дате сохраняются исходные даты файла.
- Договоры и другие уверенно распознанные посторонние PDF, обычные офисные документы, базы, архивы и прочие посторонние файлы включаются в список удаления. Файл с названием, похожим на карточку, передаётся на ручную проверку.
- Ссылки и junction не обходятся и не удаляются; они перечислены в плане.

### 2. Применение после резервной копии

Сначала просмотрите отчёт и создайте резервную копию всей исходной папки. Затем:

```powershell
.\organize-cards.ps1 -Mode Apply -Plan 'C:\Users\Admin\Desktop\kkt-sort-report\plan.json' -BackupConfirmed
```

Утилита сверяет состав архива и SHA-256 исходников с планом. Она сначала перемещает и проверяет все сохраняемые файлы, затем удаляет посторонние. Непустые старые папки не удаляются; пустые удаляются в конце. Если папка изменилась после анализа, запуск останавливается — нужен новый анализ.

`journal.jsonl` рядом с планом фиксирует начатые и завершённые операции. После обычного прерывания повторите ту же команду с тем же неизменённым `plan.json`; завершённые операции будут проверены и пропущены. Не изменяйте и не удаляйте журнал во время незавершённого переноса. При повреждении журнала потребуется ручная проверка сохранённых копий.

Проверка результата отдельно:

```powershell
.\organize-cards.ps1 -Mode Verify -Plan 'C:\Users\Admin\Desktop\kkt-sort-report\plan.json'
```

Если PowerShell блокирует запуск локального скрипта, можно вызвать консольный EXE напрямую:

```powershell
.\kkt-organizer.exe analyze --root 'C:\Users\Admin\Desktop\карточки регистрации' --report-dir 'C:\Users\Admin\Desktop\kkt-sort-report'
.\kkt-organizer.exe apply --plan 'C:\Users\Admin\Desktop\kkt-sort-report\plan.json' --backup-confirmed
```

## Сборка

Основные сборки выполняются в **GitHub Actions**. Готовое приложение доступно в [Releases](https://github.com/Lairon1/kkt-saver/releases); установщик Rust пользователю приложения не нужен.

### GitHub Actions

- **CI** (`.github/workflows/ci.yml`) запускается при push в любую ветку, при pull request и вручную. Проверяет форматирование, Clippy с запретом предупреждений, запускает все тесты и собирает оба EXE для Windows x64.
- **Build Windows** (`.github/workflows/build-windows.yml`) — общая сборка для CI и релизов на `windows-2022`. Версия Rust **1.99.1**, компоненты и целевая платформа закреплены в `rust-toolchain.toml`; зависимости — в `Cargo.lock`. Кэш ускоряет повторные сборки.
- После успешного CI в разделе **Artifacts → windows-x64** доступны `kkt-saver.exe`, `kkt-organizer.exe`, переносимый ZIP с инструкцией и лицензиями и `SHA256SUMS.txt`. Артефакты CI хранятся 14 дней.
- **Release** (`.github/workflows/release.yml`) запускается при отправке тега `v…`. Он проходит ту же сборку и тесты, проверяет контрольные суммы и публикует GitHub Release с этими файлами. Тег обязан совпадать с версией в `Cargo.toml`, например `v2.5.3`. При ошибке проверки или сборки релиз не публикуется.
- Релиз можно запустить вручную: **Actions → Release → Run workflow**, указав существующий тег. Повторная публикация уже существующего релиза завершится ошибкой; для новой версии нужен новый тег. Теги с суффиксом, например `v2.6.0-beta.1`, публикуются как предварительные релизы.

Чтобы выпустить новую версию:

1. Измените версию в `Cargo.toml`, выполните `cargo check` для обновления `Cargo.lock`, обновите инструкцию и отправьте коммит в `main`.
2. Дождитесь успешного CI.
3. Создайте тег с той же версией и отправьте его:

```powershell
git tag -a v2.5.3 -m "KKT Saver 2.5.3"
git push origin v2.5.3
```

Для последующих выпусков замените `2.5.3` на новую версию. Публикация использует встроенный `GITHUB_TOKEN`; отдельный персональный токен в Secrets не требуется. Право записи предоставлено только заданию публикации.

### Локальная сборка для разработки

Проверено: Rust 1.99.1, MSVC x64, Windows SDK. Нужны Rustup и Visual Studio Build Tools с C++/Windows SDK. Rustup автоматически использует версию и цель из `rust-toolchain.toml`. CRT статически включается в EXE.

```powershell
cd C:\Projects\kkt-saver
.\scripts\build.ps1
```

Скрипт запускает тесты и release-сборку, затем помещает EXE и уведомления о лицензиях в `dist`. Если Rust установлен локально в `.tools`, скрипт автоматически использует его. Иначе используется `cargo` из PATH.

`scripts/package.ps1` упаковывает готовый `dist` в `artifacts`: EXE, ZIP и контрольные суммы. Эти каталоги, локальный Rust, образцы карточек и результаты проверок исключены из Git.

```powershell
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --locked --release
```

Поставляемая DLL находится в `assets\bin\pdfium.dll` и встраивается при компиляции. При обычной сборке загружать PDFium из Интернета не требуется. Версия: Chromium/PDFium 8152. Проверочная SHA-256 DLL: `BA884CC5C6F2C3CD7C2ECCA9DCE36C2E341F78EB586ABD691A2BBC017AA9871E`.

### Диагностика

Извлечение данных без GUI:

```powershell
.\dist\kkt-saver.exe --inspect C:\path\card.pdf C:\path\result.json
```

Проверка поиска и скорости (архив читается, отчёт и кэш создаются локально):

```powershell
cargo run --release --locked --example validate -- C:\samples 'Z:\!Общие документы\!!!ЦТО\!КАРТОЧКИ РЕГИСТРАЦИИ' C:\reports\result.json
```

```powershell

```

## Проверки и ограничения проверки интерфейса

31 автоматический тест покрывает разбор регистрации/снятия и ИП, варианты заголовков и дат снятия, различение ИНН пользователя и ОФД, сокращения, опечатки, фамилию с инициалами, «ё/е», приоритет ИНН, конфликты имён, копирование/перенос, изменённый исходник, запрет опасных имён и сохранение в исходный путь. Отдельные тесты проверяют группировку вложенных совпадений по корневым папкам организаций, исключение папок с датами, заполнение десятки разными организациями при 900 вложенных папках одного владельца, автоматическое восстановление после недоступности архива, обнаружение новых папок без ручного обновления, запись кэша без участия GUI, создание папки, отказ от замены существующего содержимого и запрет вложенных путей вместо имени. В версии 2.1.0 проверены восемь разных настоящих PDF: пять карточек снятия с учёта и три карточки регистрации. Тип, организация, ИНН, дата, регистрационный и заводской номера сверены с образцами; хеши исходных файлов не изменились.

Новый интерфейс проверен по снимкам настоящего окна приложения: карточки регистрации и снятия, предпросмотр PDF и окно результатов поиска на локальном тестовом архиве. В версии 2.2.0 визуально проверен компактный список с десятью названиями папок, в версии 2.3.0 — кнопка и диалог создания папки. В отладочной сборке есть режим захвата собственного кадра, который не сохраняет, не переносит и не печатает карточки и не создаёт папки архива; в release-сборку этот режим не включён.

В версии 2.2.1 отдельная нативная автопроверка трижды закрывает настоящее окно в трей, восстанавливает его тем же обработчиком, который используют события трея, и запрашивает выход из скрытого состояния. Проверяется фактическая видимость HWND, атрибуты тёмной шапки DWM и выполнение штатного `on_exit`. Режим включается только в отладочной сборке через `KKT_SAVER_TRAY_CHECK_DIR` и не попадает в release. Внешний захват окна через Computer Use возвращал тайм-аут; интерактивная проверка самого значка трея, перетаскивания и системного диалога выбора папки остаётся пользовательской проверкой.

## Исходники

`src/card.rs` — данные и разбор полей; `src/pdf.rs` — PDFium, предпросмотр и Windows GDI-печать; `src/search.rs` — обход и поиск; `src/indexing.rs` — автоматическое обновление индекса и повторные попытки; `src/storage.rs` — проверка и сохранение; `src/folders.rs` — имена и создание новых папок; `src/config.rs` — настройки; `src/app.rs` и `src/app/ui.rs` — интерфейс, фоновые задачи и трей; `src/app/theme.rs` — тёмная тема и шрифты; `src/app/native_window.rs` — восстановление нативного окна и системная тёмная шапка.

Лицензии сторонних компонентов: `THIRD-PARTY-NOTICES.md`, `PDFium-LICENSE.txt` и папка `licenses` в дистрибутиве.
